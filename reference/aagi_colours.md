# Official AAGI Colours From the AAGI Comms Guide

A Vector of the official AAGI Colour Hex Codes. Other colour palettes
are provided via
[`aagi_palettes()`](https://AAGI-AUS.github.io/AAGIPalettes/reference/aagi_palettes.md)
for plotting purposes but may not considered to be "official" AAGI
colours.

## Usage

``` r
aagi_colours
```

## Format

A `vector` with eight (8) colours as hexadecimal values:

- AAGI Bright Green:

  \#B6D438

- AAGI Teal:

  \#00808B

- AAGI Blue:

  \#648FD2

- AAGI Green:

  \#54921E

- AAGI Yellow:

  \#FFBC42

- AAGI Orange:

  \#ec8525

- AAGI Black:

  \#414042

- AAGI Grey:

  \#F2F2F2
